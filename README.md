# 📚 متجر ومكتبة "تَعلّم" الإلكترونية (Ta'allam Bookstore)

منصة وتطبيق متجر إلكتروني عصري واحترافي لبيع أشهر كتب تطوير الواجهات الأمامية (**Front-End**)، لغة **JavaScript**، ومكتبة **React** و **Next.js**، بأسعار تنافسية تتراوح بين **100 إلى 450 جنيه مصري**، مع نظام سلة مشتريات ذكي وتكامل فوري ومباشر مع تطبيق واتساب على الرقم: **01018923524**.

---

## 🌟 الميزات والمواصفات الرئيسية

- 🎨 **هوية وتصميم بصري عصري (Modern Tech UI)**:
  - دعم كامل للغة العربية واتجاه اليمين إلى اليسار (RTL) بخط Cairo و Plus Jakarta Sans.
  - دعم الوضع الليلي (Dark Mode) والوضع النهاري (Light Mode) مع الحفظ التلقائي لاختيار المستخدم.
  - مؤثرات زجاجية (Glassmorphism)، تدرجات لونية، ومحاكاة ثلاثية الأبعاد لأغلفة الكتب.

- 📖 **قائمة الكتب المتوفرة (100 - 450 ج.م)**:

  4. **تعلم ريآكت: الأنماط الحديثة (Learning React 2025)** - أليكس بانكس وإيف بورسيلو — **290 ج.م**
  5. **طريقك لاحتراف ريآكت (The Road to React)** - روبن فيروخ — **270 ج.م**
  6. **ريآكت عملياً: بناء التطبيقات الكبرى (React Up & Running)** - ستاسيان ألكسندروف — **320 ج.م**
  7. **ريآكت المتقدم مع تايب سكريبت (React & TypeScript Mastery)** - نايت موراي — **450 ج.م**
  8. **إتقان Next.js 14 وتطبيقات Fullstack** - نخبة الخبراء — **420 ج.م**
  9. **الكود النظيف في جافاسكريبت (Clean Code in JS)** - جيمس بادوك — **360 ج.م**
  10. **أسرار وحيل CSS المتقدمة (CSS Secrets)** - ليا فيرو — **250 ج.م**

  12. **تصميم واجهات المستخدم للمطورين (Refactoring UI)** - ستيف شوجر — **380 ج.م**

- 🔍 **البحث والفلترة الذكية**:
  - بحث فوري وسريع (Live Search) باسم الكتاب، الكاتب، أو الموضوع.
  - شريط تصنيفات سريع (جافاسكريبت، ريآكت، HTML/CSS، تصميم الواجهات UI/UX).
  - شريط تمرير لتحديد السعر (Price Range Slider: 100 - 450 ج.م).
  - ترتيب حسب (الأكثر طلباً، الأقل سعراً، الأعلى سعراً، أعلى تقييم، الأحدث).

- 🛒 **سلة المشتريات التفاعلية (Cart Drawer)**:
  - إضافة وحذف الكتب وتعديل الكميات مع الحفظ في `localStorage`.
  - تطبيق كوبونات الخصم (مثل: `TAALAM10` لخصم 10%، `FRONTEND` لخصم 15%).
  - شريط تتبع الشحن المجاني التفاعلي.

- 💬 **الربط المباشر مع واتساب (01018923524)**:
  - إتمام الطلب بنقرة واحدة من السلة لتوليد فاتورة منسقة تنقل العميل مباشرة للواتساب.
  - نموذج بيانات الشحن (الاسم، الهاتف، المحافظة، العنوان التفصيلي، طريقة الدفع).
  - زر طلب فوري لكل كتاب على حدة.
  - زر عائم نابض للتواصل السريع والمباشر.

- 👁️ **نافذة المعاينة السريعة (Quick View Modal)**:
  - استعراض مواصفات الكتاب (عدد الصفحات، سنة الإصدار، لغة الكتاب).
  - نبذة تفصيلية ومقتطفات من فهرس الكتاب.
